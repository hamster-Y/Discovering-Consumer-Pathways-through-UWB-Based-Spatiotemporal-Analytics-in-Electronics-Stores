# Discovering-Consumer-Pathways-through-UWB-Based-Spatiotemporal-Analytics-in-Electronics-Stores
We have made publicly available the sample datasets used in the experiments, including the logs, models, and models corresponding to the real datasets. Due to commercial confidentiality agreements, we can only disclose a portion of the actual event logs obtained from the store. Additionally, the supplementary report provides a detailed description of the experimental setup, including ablation experiments with different structures, model mining, conversion and evaluation scripts, as well as the data analysis process.
